# ТИиК Тренажёр

529 заданий из «ТИиК часть2 экзамен_оценка.docx», решения всех заданий из «Ответы с gemini.md», теория по 10 темам из папки «Метода». Код и данные полностью локальные. Нет регистрации и платных сервисов.

Обновление 21 октября 2026: заменены все 529 решений. Формулы отображаются через KaTeX до обработки текста Markdown; числовые матрицы из блоков текста отображаются как математические матрицы, остальные блоки сохраняют моноширинное оформление. На компьютере добавлен файл прогресса `data/progress.json` и предыдущая резервная копия `data/progress.previous.json`.

## Быстрый запуск на Windows

1. Скопируйте **всю папку tiik-trainer** на компьютер и распакуйте архив, если он есть.
2. Дважды нажмите **Запустить.cmd**. Браузер откроет `http://localhost:8765`.
3. Окно запуска нужно оставить открытым. После первого открытия дождитесь сообщения «Готово к работе офлайн». Интернет для запуска не нужен.
4. Можно установить приложение через меню Chrome / Edge → «Установить приложение». После завершения офлайн-загрузки оно открывается без запущенного сервера.

В комплекте есть переносимый Node.js для Windows x64. Устанавливать Node.js или Python не нужно. На другом настольном устройстве с Node.js 18+ выполните `node server.cjs` из папки проекта. На Windows ARM64 запуск зависит от поддержки эмуляции x64.

Для быстрого просмотра можно открыть `app/index.html` напрямую. Для надёжного сохранения результатов и установки используйте запуск через сервер: поведение локального хранилища при открытии HTML-файлов различается между браузерами.

## Android и iPhone

Это **PWA** — устанавливаемое браузерное приложение. Нативные APK и IPA в эту сборку не входят.

Для полноценной установки на телефон требуется один раз разместить **содержимое app/** на любом статическом хостинге с **HTTPS**. Папка готова к размещению, сборка и серверная часть не нужны. Сохраняйте все подпапки и относительные пути. Файлы `.js`, `.webmanifest`, `.woff2` и `.sqlite` должны отдаваться как статические файлы. Приложение можно размещать и в подпапке. Пока публикация не выполнялась.

- **Android:** открыть HTTPS-адрес в Chrome → меню → «Добавить на главный экран» / «Установить».
- **iPhone:** открыть HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».
- До отключения интернета дождаться сообщения **«Готово к работе офлайн»**. При первом открытии загружаются все задания, разборы и иллюстрации. Разрешите достаточный объём хранилища, если браузер спросит. Не используйте приватный режим.
- После установки телефон работает самостоятельно, без включённого компьютера. Приложение не делает сетевых запросов к внешним сервисам.

Для проверки на телефоне без размещения: подключите телефон к Wi-Fi компьютера и откройте адрес из окна запуска `http://192.168.…:8765`. Может потребоваться разрешить входящие подключения в брандмауэре для частной сети. **Такой HTTP-адрес не даёт установить приложение на телефон и сохранить полную офлайн-копию.** Телефон в этом режиме требует включённого компьютера. Не открывайте порт сервера в интернет.

## Как заниматься

Выберите одну или несколько тем → настройте режим → количество **заданий** (один вопрос банка — одна единица) → начните тест. Вопросы выдаются в случайном порядке; варианты выбора тоже можно перемешивать.

Поддерживаются все форматы исходного банка: один ответ, несколько ответов, числа с допусками исходника, пропуски и сопоставление. Числа допускают точку или запятую. Текстовые ответы нечувствительны к регистру, пробелам и различию «е» / «ё». В двоичных ответах важны ведущие нули и порядок разрядов. Пропуск вопроса записывается как неверный ответ. После проверки доступен правильный ответ и разбор из конспекта; изображения можно увеличивать нажатием.

- **Ошибки:** задания, последняя попытка которых неверна. После верного решения задание выходит из этого списка, предыдущие попытки остаются в истории.
- **Давно не решённые:** задания без попыток или с последней попыткой старше выбранных 3 / 7 / 14 / 30 дней.
- **Новые:** задания без попыток.
- **Избранное:** задания с закладкой.
- **Статистика:** все вопросы банка, фильтры, история ответов конкретного задания и результаты тестов. Точность — доля верных попыток среди всех попыток. Прогресс темы — доля заданий с последним верным ответом.
- Текущий тест, проверенные ответы и введённые черновики сохраняются при каждом изменении.

## Перенос результатов

Настройки → «Скачать» → передать `tiik-progress-….json` на другое устройство → Настройки → «Загрузить». Импорт **заменяет** прогресс на принимающем устройстве после подтверждения. Автоматической синхронизации между устройствами нет.

При запуске через **«Запустить.cmd»** на компьютере прогресс автоматически записывается в **data/progress.json**. Предыдущая исправная копия сохраняется в **data/progress.previous.json**. При перезапуске выбирается самая свежая исправная копия из файла и браузера. Старые результаты из браузера автоматически подхватываются при первом запуске обновления. Не удаляйте папку `data`; при переносе приложения на другой компьютер копируйте её вместе с приложением. В распространяемый ZIP личный прогресс не включается.

В браузере используются **localStorage и IndexedDB**. При установке на телефон или размещении на статическом HTTPS-хостинге доступны обе браузерные копии и ручной экспорт; файловое сохранение относится только к запуску на локальном компьютере. Запись файла недоступна другим устройствам по Wi-Fi: у каждого телефона остаётся свой прогресс. При запуске PWA без сервера новые ответы записываются в браузер и переносятся в файл, когда сервер снова запущен. На телефоне полная очистка данных браузера удаляет обе локальные копии — регулярно экспортируйте прогресс.

## Где лежит банк

- **app/bank.sqlite** — единый переносимый SQLite-файл. Таблицы: `metadata`, `topics`, `tasks`, `assets`. Содержит задания, ключи ответов, Markdown-разборы, теорию и изображения в BLOB. Открывается любым совместимым SQLite-просмотрщиком.
- **app/bank.json** — открытая JSON-копия банка для других приложений.
- **app/bank.js** — тот же банк для работы браузера, в том числе при открытии локального HTML. SQLite не исполняется внутри браузера; это переносимый архив банка. Изменение SQLite само по себе не изменит интерфейс: нужна генерация JSON / JS.
- **app/assets/** — изображения из Word и иллюстрации из «Методы»; **app/vendor/** — локальные библиотеки форматирования Markdown и формул.
- Прогресс не записывается в банк заданий: он хранится отдельно в `localStorage`, IndexedDB, экспортируемом JSON и, при локальном запуске на компьютере, в `data/progress.json`.

Банк включает **529/529** заданий и **529/529** разборов из файла Gemini. Копия исходника сохранена в `sources/Ответы с gemini.md`; пересборка автоматически использует её для решений. Теория по темам берётся из «Методы». Ключи проверки и числовые допуски остаются из исходного Word-банка: заменены именно тексты решений. Отдельная математическая сверка всех новых решений с ключами не проводилась. Указания внутри документов используются как содержимое задач, а не как инструкции программе или разработчику.

## Исходный код и обновление

Нет этапа компиляции и пакетов для установки. Основной код: `app/app.js`, `app/engine.js`, `app/style.css`, `server.cjs`. Проверки: `node tools/test.cjs` (или `runtime/node.exe tools/test.cjs`).

Повторно импортировать исходники: `python tools/build_bank.py ПАПКА_С_ИСХОДНИКАМИ`. Python 3.10+, внешние пакеты не нужны. В папке должны находиться Word-файл и исходная папка `Метода`. Команда пересоздаёт SQLite, JSON / JS и список офлайн-ресурсов; сам исходный Word не меняет. После изменения файлов приложения повторно выполните импорт: версия офлайн-копии вычисляется автоматически по содержимому файлов. Новая версия станет доступна после перезапуска приложения с сетью. Уже открытое окно нужно перезагрузить после завершения обновления.
